The mini-GPT

  • Tokenizer: byte-level BPE (8,192 tokens) written from scratch and trained on the corpus: 3.74 bytes/token, no unknown tokens.
  • Model: decoder-only transformer, 4 pre-norm blocks, d=256, 4 heads, context 128, weight-tied LM head.
  • Pre-training: 98M tokens of L3Cube-HingCorpus tweets, 12k steps, AdamW + warmup/cosine, 40 min on a GTX 1650 (fp32: fp16 was measured 4.6× slower on this GPU). Validation perplexity 8,659 → 150.
  • Fine-tuning: classification head on the closing token; lr 3e-5, 3 epochs, 3 seeds.

What didn't work, and what it taught

  • A word-level BiLSTM overfit within 3 epochs and lost to TF-IDF: 10.5% of validation words were unknown to its vocabulary.
  • Fine-tuning the mini-GPT for 8 epochs overfit after epoch 1; short runs with the learning rate decaying over the whole run added ~1 F1.
  • Contextual calibration made few-shot Qwen worse: its content-free inputs ("N/A") are genuinely neutral, so dividing out that "bias" removed the neutral class.
  • fp16 mixed precision was 4.6× slower than fp32 on a GPU without tensor cores. Measure before assuming.
  • Three times the best hyperparameter sat at the edge of the search range; extending the range changed or confirmed the result each time.

Run it yourself

The full live demo (classify with all three models, generate text, attention maps) runs locally:

pip install -r requirements.txt && pip install -e .
python -m minigpt.export_app
python app/app.py
